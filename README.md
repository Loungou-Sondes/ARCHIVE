# Système de gestion des archives intermédiaires

Application web dédiée à la **gestion des archives intermédiaires de l’OMMP (Office de la Marine Marchande et des Ports)**.

## Fonctionnalités

*  Authentification et gestion des rôles
*  Gestion des archives et des emplacements
*  Gestion et validation des bordereaux
*  Recherche multicritère
*  Tableau de bord et indicateurs
*  Alertes sur le cycle de vie des archives
*  Assistance par IA

## Technologies

* **Frontend :** Angular, PrimeNG
* **Backend :** Spring Boot, Java
* **Base de données :** Oracle
* **Sécurité :** Spring Security
* **Outils :** Docker, Git, GitHub

## Contexte

Projet de **fin d’études (PFE)** réalisé pour améliorer la gestion, le suivi et la recherche des archives intermédiaires au sein de l’OMMP.
